# Документация сервиса промокодов: promo_service

---

Хранит скидочные кампании в таблице promocodes и обрабатывает их применение. Валидирует активность кода, срок его действия (expires_at) и атомарно инкрементирует счетчик current_uses с контролем общего лимита max_uses, исключая состояние гонки при одновременных заказах.


---

## Данные

- `promocodes` (Table / PostgreSQL): Единая таблица хранения и контроля промокодов скидок:
  - `id` (SERIAL, Primary Key): Уникальный идентификатор записи.
  - `code` (VARCHAR, Unique, Not Null): Уникальный буквенно-цифровой промокод (индексирован).
  - `discount_percent` (INT, Not Null): Размер скидки в процентах (`CHECK (discount_percent > 0 AND discount_percent <= 100)`).
  - `max_uses` (INT, Not Null): Максимально допустимое суммарное число активаций.
  - `current_uses` (INT, Default 0): Текущее количество совершенных активаций (`CHECK (current_uses <= max_uses)`).
  - `is_active` (BOOLEAN, Default TRUE): Флаг принудительной ручной блокировки промокода.
  - `expires_at` (TIMESTAMP WITH TIME ZONE, Not Null): Дата и время окончания действия промокода.

---

## Пользовательские роли

- **INTERNAL SERVICE / GATEWAY:** Запросы, проходящие через API-шлюз от имени авторизованного клиента в момент оформления заказа (проверка валидности кода и атомарное списание лимита).
- **ADMIN:** Роль управления маркетинговыми кампаниями (создание новых промокодов, изменение лимитов активаций, деактивация).

---

## API

- **POST /api/v1/promocodes/apply**
  - **Описание:** Проверка валидности введенного промокода и атомарное инкрементирование счетчика `current_uses` с контролем лимита `max_uses` и срока действия.
  - **Возвращает:** Процент скидки и статус применения, либо ошибку `400 Bad Request` / `404 Not Found` (код не найден, исчерпан или просрочен).

- **POST /api/v1/promocodes**
  - **Описание:** Создание новой скидочной кампании (доступно для роли ADMIN).
  - **Возвращает:** Объект созданного промокода со всеми лимитами.

- **GET /api/v1/promocodes/{code}**
  - **Описание:** Просмотр текущего состояния и остатка использований промокода без его списания.
  - **Возвращает:** Метаданные промокода.

## Технологии разработки

**Язык программирования:**
- Python 3.11+.
- Основной фреймворк: FastAPI (асинхронная обработка запросов ASGI).
- Валидация и сериализация данных: Pydantic v2.
- Асинхронный драйвер БД и ORM: SQLAlchemy 2.0 (AsyncIO) / asyncpg.
- Миграции базы данных: Alembic.

**СУБД:**
- PostgreSQL 16+.
