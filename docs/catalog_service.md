## Описание

-   Наименование: Микросервис каталога товаров
    
-   Предметная область: Управление ассортиментом

## Данные

1.  Таблица `products` (Позиции меню)
    
    -   id (SERIAL): Первичный ключ.
        
    -   name (VARCHAR): Название позиции (например, "Латте"). Ограничение:  NOT NULL.
        
    -   price (NUMERIC): Цена товара. Ограничение:  NOT NULL,  CHECK (price >= 0) (защита от отрицательных цен).
        
    -   category (VARCHAR): Категория товара. Ограничение:  NOT NULL.
        
    -   is_available (BOOLEAN): Статус наличия товара. Значение по умолчанию:  DEFAULT TRUE.
        
    -   image (VARCHAR): Относительный URL-путь до файла с картинкой товара на сервере.
        

Общие ограничения целостности:

-   Доменная целостность: Ограничение CHECK на уровне базы защищает бизнес-логику от ошибочного ввода отрицательных цен. Ограничения NOT NULL гарантируют, что товар не будет создан без имени или цены.
    
-   Сущностная целостность: Использование первичного ключа типа SERIAL для однозначной идентификации каждой позиции.
    

## Пользовательские роли

-   ADMIN.
    
    -   _Ответственность:_ CRUD операции. Добавление новых позиций, изменение, удаление, загрузка файлов картинок.
        
    -   _Количество:_ Ограничено.
        
-   USER.
    
    -   _Ответственность:_ чтение данных.
        
    -   _Количество:_ Неограниченно.
        
-   Внутренний микросервис (Order Service).
    
    -   _Ответственность:_ HTTP-запрос цены конкретного товара по его ID (`GET /menu/id`) перед оформлением заказа.
    -   _Количество:_ 1-5 экземпляров микросервиса.

## UI / API

Взаимодействие с микросервисом происходит через REST API. Сервис работает исключительно как бэкенд. Также реализована раздача статических файлов (картинок товаров) напрямую через веб-сервер.

-   Основные маршруты API:
    
    -   GET /api/v1/menu - Получение списка всего меню.
        
    -   GET /api/v1/menu/id - Получение информации о конкретном товаре.
        
    -   POST /api/v1/menu - Добавление нового товара.
        
    -   PUT /api/v1/menu/id - Обновление данных товара (цены, названия).
        
    -   DELETE /api/v1/menu/id - Удаление товара из базы.
        
-   Работа с файлами: UploadImage для загрузки изображений товаров

## Технологии разработки

-   Язык программирования: Go (Golang). Использован фреймворк Gin для HTTP-маршрутизации.
    
-   СУБД: PostgreSQL. Подключение реализовано через пул соединений pgxpool.
    
-   Логирование и надежность: Используется библиотека zap для структурированного логирования HTTP-запросов через собственный LoggerMiddleware. Реализован механизм Graceful Shutdown (плавное завершение работы) - при остановке сервера он ждет до 5 секунд, чтобы успешно завершить текущие запросы к базе данных.
    
-   Конфигурация: Переменные окружения (порт, доступы к БД) подгружаются из .env файла через библиотеку godotenv.

- Тестирование: Тестирование API выполняется в Postman.
