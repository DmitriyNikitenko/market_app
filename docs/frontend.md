# Описание Frontend

---

Отвечает за пользовательский интерфейс витрины, корзины и оформления покупки. Работает по гибридной модели (Server и Client Components), сохраняет клиентскую сессию и локальное состояние корзины в localStorage через Zustand, отправляет асинхронные запросы исключительно в api_gateway.

---

## Данные

- **`auth_session`** *(Object / Storage)*: JWT-токен сессии и данные профиля пользователя (`id`, `email`, `name`). Хранятся на стороне клиента в `localStorage` с синхронизацией через состояние Zustand. Токен передается в заголовке `Authorization: Bearer <token>` во всех защищенных запросах к API-шлюзу.
- **`cart_state`** *(Object / Storage)*: Локальное состояние позиций в корзине (`items: [{ product_id, quantity }]`). Сохраняется в кэше клиента для быстрого отклика UI и синхронизируется с `order_service` при оформлении заказа.
- **`catalog_cache`** *(Array)*: Данные витрины товаров, получаемые через API-шлюз из сервиса каталога для отображения карточек на страницах.

---

## Пользовательские роли

- **`UNAUTHENTICATED` (Анонимный гость):** Имеет доступ к просмотру страниц каталога товаров (`/`, `/products`), локальному наполнению корзины (`/cart`), а также формам регистрации и авторизации (`/login`).
- **`USER` (Авторизованный покупатель):** Получает доступ к оформлению заказов, применению скидочных промокодов, просмотру профиля и истории покупок.
- **`ADMIN` (Администратор):** Получает доступ к административным панелям управления каталогом и мониторинга заказов при наличии соответствующего claim в JWT.

---

## API

Клиентское приложение не предоставляет публичный API, а выступает потребителем (*consumer*) ресурсов API-шлюза:

- **`GET /api/products`**
  - **Описание:** Получение списка товаров и цен из сервиса каталога для формирования витрины.

- **`POST /api/auth/login`**, **`POST /api/auth/register`**
  - **Описание:** Передача учетных данных в сервис аутентификации через шлюз для получения сессионного JWT.

- **`POST /api/orders`**, **`GET /api/cart`**
  - **Описание:** Взаимодействие с сервисом заказов для синхронизации корзины и оформления покупки.

- **`POST /api/promocodes/apply`**
  - **Описание:** Отправка промокода на валидацию и расчет скидки перед чекаутом.

## Технологии разработки

### Язык программирования и стек
- **Язык программирования:** TypeScript (JavaScript ES2023+)
- **Основной фреймворк:** Next.js 14+ (App Router, Server & Client Components)
- **Библиотека UI:** React 18+
- **Стилизация:** Tailwind CSS
- **Управление состоянием:** Zustand (с middleware `persist` для LocalStorage)
- **Иконки:** Lucide React

### СУБД
- Отсутствует *(клиентское состояние: RAM + Web Storage API / LocalStorage)*
